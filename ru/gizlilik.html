2. Обрабатываемые данные и цели обработки

a) Статистика использования сайта

На нашем сайте используются файлы cookie Google Analytics для измерения и повышения качества обслуживания. Эти файлы cookie собирают анонимные статистические данные: посещённые страницы, продолжительность сессии и общие тенденции использования. Эти данные не используются для идентификации конкретных лиц.

b) Анонимный счётчик посетителей

На нашем сайте отображается счётчик посетителей в реальном времени. Счётчик работает на основе случайного идентификатора сессии, не содержащего персональных данных. Идентификатор сессии удаляется при закрытии браузера; имя, адрес электронной почты и IP-адрес не сохраняются.

c) Контактная форма

Имя, адрес электронной почты и текст сообщения, отправленные через контактную форму на нашем сайте, обрабатываются исключительно для ответа на ваш запрос. Данные формы передаются через инфраструктуру Formspree и не передаются третьим лицам.

d) Общение через WhatsApp и Telegram

При обращении к нам через WhatsApp или Telegram действуют политики конфиденциальности и условия использования соответствующих платформ. Информация, которой вы делитесь на этих платформах, подчиняется правилам обработки данных соответствующей платформы.

3. Хранение и передача данных

Ваши персональные данные не продаются и не используются в маркетинговых целях третьими лицами и не передаются в коммерческих целях.

Данные передаются только тем поставщикам инфраструктуры, которые технически необходимы для работы сервиса:

  • Google — Аналитика сайта и измерение производительности
  • Formspree — Инфраструктура контактной формы
  • Supabase — База данных счётчика посетителей (анонимная)
  • Netlify — Инфраструктура хостинга сайта

Эти поставщики инфраструктуры действуют в рамках собственных политик конфиденциальности.
