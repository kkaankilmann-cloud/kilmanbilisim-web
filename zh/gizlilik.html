2. 处理的数据及目的

a) 网站使用统计

本网站使用 Google Analytics Cookie，用于衡量和改进我们的服务质量。这些 Cookie 收集访问页面、会话时长和总体使用趋势等匿名统计数据。这些数据不会用于识别个人身份。

b) 匿名访客计数器

本网站设有实时访客计数器。该计数器通过不包含个人数据的随机会话标识（session ID）运行。会话标识在浏览器关闭时删除；不会记录姓名、电子邮箱或 IP 地址。

c) 联系表单

您通过本网站联系表单提交的姓名、电子邮箱和留言内容，仅用于回复您的请求。表单数据通过 Formspree 基础设施传输，不会与第三方共享。

d) WhatsApp 与 Telegram 沟通

当您通过 WhatsApp 或 Telegram 与我们联系时，适用相关平台自身的隐私政策和使用条款。您通过这些平台分享的信息，受相应平台的数据处理规则约束。

3. 数据的存储与共享

您的个人数据不会被出售、不会被用于营销，也不会因商业目的与第三方共享。

数据仅与服务技术运行所必需的基础设施提供商共享：

  • Google — 网站分析与性能测量
  • Formspree — 联系表单基础设施
  • Supabase — 访客计数器数据库（匿名）
  • Netlify — 网站托管基础设施

这些基础设施提供商在其各自的隐私政策框架内行事。

4. 您在 KVKK 下的权利

依据土耳其第6698号个人数据保护法第11条，您享有以下权利：

  • 🔍
    知情权： 了解您的个人数据是否被处理以及处理目的。
  • ✏️
    更正权： 在个人数据处理不完整或不正确时，要求予以更正。
  • 🗑️
    删除权： 在处理所需理由消失时，要求删除或销毁您的数据。
  • 🚫
    异议权： 对完全由自动化系统分析处理数据而产生的不利结果提出异议。
  • 💰
    赔偿权： 因违法处理数据而遭受损失时，要求赔偿。

如需行使上述权利，您可通过 info@kilmanbilisim.com 提出申请。您的申请将在最迟 30 天内得到答复。
